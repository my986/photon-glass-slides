1 · Overview

What PHOTON GLASS is made of

A glasses-type device that turns what a first-person camera sees into feedback such as speech. The sample program reads captured text aloud.

On the glasses

Camera unit

Camera, shutter (camera button) and camera board. One HDMI cable connects it to the main unit.

In a pocket or around the neck

Main unit

Raspberry Pi Zero 2 W and the main board. Speaker, four buttons, a status LED and a volume knob.

Python

Program

Waits for a button, takes a photo, runs text recognition and speech synthesis through cloud APIs, and plays the result.

2 · Where information goes

GitHub vs. Scrapbox

GitHub (photonglass/photonglass)Scrapbox (class projects)
VisibilityPublic (anyone can read it)Private (members only)
ContentsDesign data, programs, build and setup guides, licencesClass preparation and running order, network and access details, notes for students
How it is updatedChanges go on a branch and are reviewed in a pull request before merging into main. Full history is keptMembers edit pages directly. Suited to information that changes every class
Questions, reportsBugs and suggestions go to IssuesClass announcements, problems on the day
Never writePasswords, API keys, Wi-Fi names and passwords, IP addresses(Allowed, since it is private — but never copy them to GitHub)

Rule of thumb

If everyone who builds or fixes PHOTON GLASS needs it, it goes on GitHub. If it only serves this class, it goes on Scrapbox.

3 · Circuit · animation

The audio signal path

Now: no earphones → speaker plays
More

Pi → DAC uses three I2S lines: BCK (bit clock) = physical pin 12, LRCK (left/right clock) = 35, DIN (data) = 40. The PAM8304 is a class-D amplifier: it amplifies by fast switching, so little power is lost as heat.

Obsolete parts replaced

Some parts in the original 2019 design are no longer available. They were replaced with current parts, and every pinout was checked against its datasheet (0 mismatches).

Revision is on the silkscreen

Main board 2026 / PB-4, camera board 2026 / PC-4. Check the silkscreen to see which revision you have.

3 · Extending

Room for extension

Buttons

Three unused buttons

Main (GPIO27), up (GPIO23) and down (GPIO24) are unused by the current program. Assign them to, for example, repeat or change speaking speed.

Program

Read main_seq.py first

The sequential version does one step at a time and is easy to follow. What actually runs is the asynchronous version, which responds to buttons mid-process: main_async.py.

Enclosure

Parametric enclosure

The camera unit is defined in src/camera_case.py (CadQuery). Change dimensions and rerun to regenerate every part.

Changes can be undone

If a change breaks the program, run photonglass-reset on the Raspberry Pi to restore the original (changed files are kept in a backup folder).
