# PHOTON GLASS 授業スライド

メガネ型デバイス PHOTON GLASS のドキュメント（GitHub）と電気回路を説明する、授業用のスライドです。
ブラウザで `index.html` を開くと表示されます（3D の部品は、マウスや指で回せます）。
英語版は `en.html` です。画面右下の「EN」「日本語」のボタンで、同じページのまま切り替えられます。

English version: open `en.html` (or press “EN” at the bottom right).

## 操作
- ← → キー：ページ送り
- N キー：話す人用のメモの表示・非表示
- F キー：全画面

## もとになっているデータ
PHOTON GLASS の設計データ・プログラム・手順書は [photonglass/photonglass](https://github.com/photonglass/photonglass) にあります。
